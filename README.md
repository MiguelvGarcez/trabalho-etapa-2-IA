# Sistema Especialista Inteligente para Mapeamento e Trilha de Carreira em TI

Este projeto consiste no desenvolvimento de um sistema especialista inteligente que tem como objetivo auxiliar pessoas na identificação de possíveis caminhos profissionais na área de Tecnologia da Informação (TI).

Por meio de um questionário interativo, o sistema analisa as afinidades, preferências e conhecimentos técnicos do usuário para identificar quais áreas da TI apresentam maior compatibilidade com seu perfil.

Com base nas respostas, o sistema utiliza um mecanismo de inferência para calcular e apresentar as três trilhas profissionais mais compatíveis, acompanhadas de seus respectivos percentuais e justificativas.

Além disso, a aplicação identifica lacunas de conhecimento (*Skill Gap*) e apresenta um roadmap personalizado, com sugestões de tecnologias, certificações e projetos práticos para auxiliar o usuário a desenvolver as habilidades necessárias para alcançar o nível profissional Júnior.

O sistema contempla dez trilhas profissionais da área de TI, funcionando como uma ferramenta de apoio à orientação de carreira e ao planejamento do desenvolvimento profissional.
